# vrpg

AI-generated RPG: an LLM (via OpenRouter or Codex with a ChatGPT subscription) runs the story as branching choices, Minimax H3 Max Turbo (via Fal) renders each chosen action as an 8-15s third-person clip (length picked by the LLM) continuing from the last frame of the previous clip. Clips play the moment they render; the idle loop and next choices generate behind the playback. The player controls one character, described by appearance in prompts like any other character in the scene. See spec.md for details.

Run with `npm start` (needs `.env` with `FAL_API_KEY` and, for OpenRouter, `OPENROUTER_API_KEY`, plus `ffmpeg` on PATH), then open http://localhost:3000. Pick OpenRouter or Codex and a compatible model. Codex requires the `codex` CLI on PATH; select it and use Connect ChatGPT once to authorize this local app. Its credentials stay under the ignored `data/codex-home/` directory. An idle loop of the opening scene plays while you pick your first choice, then pick choices as clips render — or type your own idea into the fourth box and the LLM writes an action inspired by it. An "idle loops" toggle next to the model picker disables loop rendering and display entirely: the frozen frame stands between turns instead, saving one 5s loop render per turn. The timeline sidebar (top-left toggle) lists every turn: click to rewind and rewatch, change the model for the next turn, or delete everything after a point to branch the story from there. Session media and the story transcript land in `data/<timestamp>/`; one in-memory session at a time. Past stories are listed on the start screen, where they can be resumed, rendered into a single downloadable `story.mp4` (plain, or "Render + Choices" to overlay each turn's options at its clip's start with the picked one highlighted green), or deleted.

Cost: ~$0.03 per 5s of clip at the 480p launch rate (~$0.13 after Sept 7 2026), $0.04 per opening frame, LLM cost negligible. A tracker at the bottom of the timeline sidebar shows the active story's API spend (exact for OpenRouter, rate-estimated for Fal), persisted per story. ChatGPT subscription usage is subject to Codex plan limits and is not shown as dollar spend.
