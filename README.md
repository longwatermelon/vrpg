# vrpg

AI-generated RPG: an LLM (via OpenRouter) runs the story as branching choices, Minimax H3 Max (via Fal) renders each chosen action as an 8-15s third-person clip (length picked by the LLM) continuing from the last frame of the previous clip. Clips play the moment they render; the idle loop and next choices generate behind the playback. The player controls one character, described by appearance in prompts like any other character in the scene. See spec.md for details.

Run with `npm start` (needs `.env` with `FAL_API_KEY` and `OPENROUTER_API_KEY`, plus `ffmpeg` on PATH), then open http://localhost:3000. Describe your character and starting scenario, then pick any compatible OpenRouter model and reasoning effort. An idle loop of the opening scene plays while you pick your first choice, then pick choices as clips render — or type your own idea into the fourth box and the LLM writes an action inspired by it. The timeline sidebar (top-left toggle) lists every turn: click to rewind and rewatch, change the model for the next turn, or delete everything after a point to branch the story from there. Session media and the story transcript land in `data/<timestamp>/`; one in-memory session at a time. Past stories are listed on the start screen, where they can be resumed, rendered into a single downloadable `story.mp4` (plain, or "Render + Choices" to overlay each turn's options at its clip's start with the picked one highlighted green), or deleted.

Cost: ~$0.13 per 5s of clip (480p; doubles to ~$0.25 when the launch promo ends Sept 1 2026), $0.04 per opening frame, LLM cost negligible. A tracker at the bottom of the timeline sidebar shows the active story's spend (exact for OpenRouter, rate-estimated for Fal), persisted per story.
